# MUSIC_LICENSES.md — Mark Hanna documentary

> **Provenance contract.** Per PLAN §3.6 (binary copyright protocol), every cue that ships
> in this documentary must have all four mandatory provenance fields filled in this file
> before the unlisted YouTube upload. Missing any field → cue does not ship.
>
> The four mandatory fields per cue are:
> 1. **Source URL** — the live page hosting the recording (LoC item, IA item, Musopen
>    track, IMSLP file, FMA track, or Suno song page).
> 2. **License text** — the actual license/rights statement quoted from the source page,
>    plus a live URL to the license (CC, Public Domain Mark, MMA reference, Suno ToS, etc).
> 3. **Attribution string** — the literal text that goes into the YouTube description
>    crediting the source.
> 4. **Date downloaded** — YYYY-MM-DD when the editor pulled the asset.
>
> AI-generated cues additionally require:
>
> 5. **Prompt** — the exact prompt used to generate the cue.
> 6. **Model name** — e.g. "Chirp v4.5" or whatever the active Suno model name is at
>    generation time.
> 7. **Generation date** — YYYY-MM-DD of the generation.
> 8. **TOS screenshot path** — relative path to the screenshot of the paid-tier ToS
>    captured on the day of generation, e.g. `assets/suno-tos-screenshot-2026-06-15.png`.
>
> Cells marked `<TBD by editor>` are placeholders. The editor fills them at audition
> time and re-fills them at final-mix time if the cue is swapped.
>
> See also: `research/music/PERSPECTIVE-LICENSE.md` for per-source license text,
> composition-vs-recording PD verification rules, and the Content ID dispute kit.
